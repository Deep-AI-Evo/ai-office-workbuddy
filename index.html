1课前准备：装好 workbuddy

建议课前1天完成安装，避免现场网络拥堵

步骤1：下载客户端

  1. 用电脑浏览器访问官网：www.workbuddy.cn
  2. 点击「下载客户端」
  3. 根据系统选择：Windows（10/11）或 Mac（macOS 10.15+）

步骤2：安装并登录

  1. 双击安装包，按提示完成安装
  2. 打开 workbuddy，用微信扫码登录
⚠️ 登录遇到问题？检查网络连接，或切换网络（公司网络可能有限制）

步骤3：授权工作目录（关键！）

workbuddy 要操作你的文件，必须先授权。

  1. 桌面新建文件夹，命名 workbuddy练习
  2. 打开 workbuddy，根据提示进行目录授权
  3. 选择刚创建的文件夹授权
🔒 安全提示：只授权专门的练习文件夹，不要授权整个硬盘或敏感目录！涉及机密先脱敏。

左侧新窗口开多个任务并行同时做几件事

2认识 workbuddy：3分钟看懂

workbuddy 是什么？

一句话：腾讯出品的全场景职场AI智能体桌面工作台。

它不是"会聊天的顾问"（给你一段文字），而是"会动手干活的员工"——你给它一个目标，它自己读文件、写文档、做表格，直接给你一个能用的成品文件。

核心能力速览

能力说明典型场景
🎯 任务规划执行Ask简单问答 / Plan复杂任务拆解做周报、写方案
💻 操作本地电脑读文件、写文档、整理文件夹、发邮件发票整理、批量重命名
📦 多模态交付直接产出 Word/Excel/PPT/PDF/海报做PPT汇报、出报表
⚡ 多Agent并行开多个窗口同时跑多个任务一边周报一边整理文件
🧩 技能包Skills内置20+技能，可自定义固化重复工作每月固定格式的工作

两种模式怎么选？

Ask 模式Plan 模式

3课堂练习：4大任务实操

以下任务课堂上跟着讲师做，这里提供详细步骤方便课后复习

📝 任务1：周报自动化（约15分钟）

目标：把一周的工作素材，变成一份结构完整的周报。

操作步骤

  1. 打开 workbuddy，切换到 Plan 模式
  2. 复制下方指令，把 [ ] 里内容改成自己的
  3. 粘贴发送，看AI列出的计划，确认后执行
  4. 到练习文件夹查看生成的 Word 成品

指令模板

角色：你是壹我科技公司市场部经理林小溪，正在写第30周（7.15-7.21）工作周报。 资料：请读取"练习素材/周报素材"文件夹里的三个文档： - 本周活动复盘.docx - 客户反馈表.xlsx - 下周计划草稿.txt 要求：生成一份周报，包含以下板块： 1. 本周工作总结（提炼3-5条重点成果，用数据说话） 2. 遇到的问题与解决思路 3. 下周工作计划（分主次） 4. 需要领导协调的事项 语气：专业、简洁、有结果导向，不要空话套话。 输出格式：Word 文档，保存到练习文件夹，文件名"周报_W30_林小溪"。

✅ 检查成果

  • 生成了 周报_W30_林小溪.docx
  • 打开后有4个清晰板块
  • 内容基于素材，不是瞎编的
📋 任务2：会议纪要（约12分钟）

目标：把会议速记，变成结构化纪要 + 行动项清单。

操作步骤

  1. 确认素材在 练习素材/会议纪要素材/
  2. Plan 模式下输入下方指令
  3. 执行后查看：一个 Word 纪要 + 一个 Excel 行动项

指令模板

任务：把以下会议录音转写文本，整理成一份结构化会议纪要。 资料：读取"练习素材/会议纪要素材/市场部Q2季度复盘会议速记.txt"。 输出结构： 1. 会议基本信息（时间、议题、参会人——从文本提取） 2. 核心决议（列出会议达成的所有决定，约7条） 3. 各议题讨论要点（按议题分组，每条不超过2句话） 4. 行动项清单（做成表格：任务 | 负责人 | 截止时间 | 验收标准） 额外要求： - 把所有"大概、可能、尽快、待会儿、回头"这类模糊表述，标注出来提醒我确认 - 行动项清单单独导出一个 Excel 输出：纪要存为 Word，行动项存为 Excel，都放练习文件夹。
💡 技巧：你公司有自己的纪要格式，直接把模板贴进指令，AI会照你的格式来。
🎨 任务3：PPT汇报一键生成（约15分钟）

目标：从一份资料文档，一键生成可用的汇报PPT。

操作步骤

  1. 确认素材在 练习素材/PPT素材/
  2. Plan 模式输入指令（重点改"受众""页数""结构"）
  3. 执行后打开生成的PPTX，检查并手动微调

指令模板（口诀：四给）

任务：根据资料文档，生成一份汇报 PPT。 资料：读取"练习素材/PPT素材/智能办公本Pro产品市场分析.docx"。 PPT 要求： - 受众：公司中层管理者（非技术背景，要听得懂） - 页数：10-12 页 - 风格：商务、简洁、蓝白配色 - 内容结构： 1. 封面（标题 + 汇报人 + 日期） 2. 目录 3. 市场背景与规模（2页，要有数据图表） 4. 竞品对比（做一个对比表格，1页） 5. 我们的核心优势（2页，要有数据支撑） 6. 销售表现（1页，含关键数据） 7. Q3策略建议（2页，要具体可执行） 8. 总结与下一步 - 每页2-4个要点，不要堆满文字 - 数据部分请生成图表（柱状图/饼图） 输出：PPTX 文件，存到练习文件夹。
⚠️ 必做人工核对：① 配图检查（有无"开天窗"，手动补图）② 数据核对（关键数字自己算一遍）。把AI输出当80分初稿，你改20分钟到90分。
🗂️ 任务4：文件整理自动化（约8分钟）

目标：把散乱文件，按规则自动重命名 + 分类归档。

操作步骤

  1. 确认素材在 练习素材/待整理/（发票图片+Word+Excel，文件名都是乱的）
  2. 输入下方指令
  3. 查看整理结果 + 汇总清单

指令模板

任务：整理"练习素材/待整理"文件夹。 规则： 1. 发票子文件夹里的图片，识别每张发票内容，按"日期_开票方_金额"格式重命名，移到"发票_已整理"文件夹 2. 文档子文件夹里的 Word，读取内容后按"主题_日期"格式重命名，移到"文档_已整理"文件夹 3. 表格子文件夹里的 Excel，移到"表格_已整理"文件夹 4. 其他无法归类的，放进"其他"文件夹并列表告诉我 整理完，给我一个汇总清单（Excel）：列明每个文件原名→新名→归到了哪个文件夹→发票金额（如有）。
🚀 进阶玩法·Skill技能：这种整理每月都做？把它存成一个技能，下次点一下就自动跑。详见指令库附录B。

4黄金四件套：写出好指令

课堂反复强调的指令万能公式。以后写任何指令，照这四步来：

步骤内容作用
① 角色你是谁？（市场专员/HR/财务）决定AI用什么语言
② 资料读哪些文件？（指明文件名）决定AI基于什么内容
③ 要求要什么结构？（列出板块）决定AI按什么格式输出
④ 语气+格式什么风格？存成什么？决定输出能不能直接用
❌ 差指令

"帮我做个周报"

✅ 好指令

"你是市场运营专员，读取活动复盘.docx和客户反馈表.xlsx，生成含本周总结、问题、下周计划三个板块的周报，语气专业简洁，输出Word存练习文件夹。"

💡 指令写得好，效果翻十倍。

6常见问题 FAQ

Q1：workbuddy 收费吗？

基础功能可免费体验。重度使用有付费方案（以官网为准）。先用免费版练手。

Q2：数据安全吗？会泄露机密吗？

只授权指定文件夹，别授权敏感目录；机密内容先脱敏；企业大规模用有企业版，数据隔离更严。

Q3：能操作公司内部系统（OA/ERP）吗？

主要操作电脑上的文件和常用软件。直接登录操作ERP/OA能力有限，但可导出数据再手动录入。

Q4：做的PPT/周报领导能看出是AI写的吗？

直接交可能会。正确做法是当初稿，加自己的判断和润色。AI帮你省80%体力活，20%脑力活还是你的。

Q5：Mac能用吗？

能，支持 macOS 10.15+。

Q6：和豆包/ChatGPT比学哪个？

不冲突。豆包/ChatGPT适合"问个事、写句话"（对话型）；workbuddy适合"把活干完、交成品"（执行型）。两个都用效率最高。

Q7：生成文件在哪找？

默认保存在授权的工作目录里。找不到就检查指令里是否明确说了"保存到练习文件夹"。

Q8：任务失败了/结果不对怎么办？

  1. 检查是否切到 Plan 模式
  2. 检查指令是否写全黄金四件套
  3. 检查文件名是否正确
  4. 检查授权目录是否包含目标文件
  5. 还不行→发学习群求助

1周报 / 月报 / 汇报类

📝 4条指令 ｜ 日报、周报、月报、季度述职

📝 标准周报最常用
适用：运营/市场/产品/行政/HR/财务（改"角色"即可）
角色：你是一名[市场运营]专员，正在写本周（第[30]周）工作周报。 资料：请读取我练习文件夹里这三个文档： - [本周活动复盘.docx] - [客户反馈表.xlsx] - [下周计划草稿.txt] 要求：生成一份周报，包含以下板块： 1. 本周工作总结（提炼3-5条重点成果，用数据说话） 2. 遇到的问题与解决思路 3. 下周工作计划（分主次，标注优先级） 4. 需要领导协调的事项 语气：专业、简洁、有结果导向，不要空话套话。 输出格式：Word 文档，保存到练习文件夹，文件名"[周报_W30]"。
📊 月度工作总结（带数据复盘）
角色：你是一名[销售经理]，正在撰写[7月]度工作总结。 资料：读取练习文件夹里的： - [7月销售数据.xlsx] - [重点客户跟进记录.docx] - [团队周报合集.pdf] 要求：生成月度总结，包含： 1. 月度目标完成情况（目标 vs 实际，达成率，用数据对比） 2. 重点工作回顾（3-5项，每项含：做了什么、结果如何、关键数据） 3. 亮点与不足（各列3条，要具体） 4. 下月计划与目标（量化目标 + 关键动作） 5. 需要支持的事项 语气：客观、数据导向、有反思深度。 输出：Word 文档 + 一张目标达成率的柱状图（单独存为图片），都放练习文件夹。
🎯 季度述职报告
角色：你是一名[产品经理]，准备[Q3]季度述职。 资料：读取练习文件夹里的[Q3季度项目汇总.docx]和[用户增长数据.xlsx]。 要求：生成述职报告，结构如下： 1. 季度概述（一段话总结整体表现） 2. 核心业绩（用OKR框架，列出3-5个目标及完成度） 3. 重点项目复盘（选2-3个重点项目，含背景/动作/成果/反思） 4. 数据亮点（提炼3-5个关键数据指标的变化） 5. 不足与改进方向 6. 下季度规划 语气：正式、有高度、突出价值和贡献。 输出：Word 文档，15-20页规模，存练习文件夹，文件名"[Q3述职报告]"。
⚡ 日报 / 站会快报（轻量版）
任务：帮我生成今日工作日报。 我今天做的事： - [上午参加了XX项目评审会] - [完成了XX方案的初稿] - [回复了15封客户邮件] 要求：整理成日报格式： 1. 今日完成事项（按重要性排序） 2. 进行中事项（进度百分比） 3. 明日计划（3条以内） 4. 需要协调/阻塞事项（没有就写"无"） 语气：简洁、干练，每条不超过1行。 输出：直接在对话框给我文本即可，不用存文件。

🤝 客户 / 商务会议纪要（带下一步行动）
任务：整理一场客户沟通会的纪要。 资料：读取"[XX客户拜访会议记录.txt]"。 要求： 1. 客户基本信息（公司、参会人、角色） 2. 客户表达的需求与痛点（逐条列出，标注重要程度） 3. 我方提出的方案与客户反馈（哪些认可、哪些有疑虑） 4. 客户提到的竞品/替代方案 5. 关键承诺与共识 6. 下一步行动项（表格：行动 | 负责人 | 截止日 | 给客户的交付物） 特别提醒：把客户提到的所有"数字"（预算、时间节点、规模）单独高亮列出，方便我核对。 输出：Word 纪要 + Excel 行动项。

🎨 工作汇报 PPT最常用

任务：根据资料文档，生成一份汇报 PPT。 资料：读取练习文件夹里的"[XX产品市场分析.docx]"。 PPT 要求： - 受众：[公司中层管理者（非技术背景，要听得懂）] - 页数：[10-12 页] - 风格：[商务、简洁、蓝白配色] - 内容结构： 1. 封面（标题 + 汇报人 + 日期） 2. 目录 3. 市场背景（2页） 4. 竞品对比（做一个对比表格，1页） 5. 我们的优势（2页，要有数据支撑） 6. 策略建议（2页，要具体可执行） 7. 总结与下一步 - 每页要有 2-4 个要点，不要堆满文字 - 数据部分请生成图表（柱状图/饼图） 输出：PPTX 文件，存到练习文件夹。

技巧2：给AI"样例"效果更好

任务：撰写客服话术。 参考这个风格： "您好，感谢您联系XX，关于您反馈的[问题]，我们已经记录，预计[时间]内给您回复，给您带来不便深表歉意。" 请按这个风格，为以下5种常见问题各写一段话术： 1. 物流延迟 2. 商品破损 3. 退款咨询 ...

技巧3：复杂任务拆成几步

  • 第1步："先读取文件，告诉我里面有哪些关键信息"（确认AI理解对了）
  • 第2步："基于这些信息，按XX结构生成周报"（再执行）

技巧4：让AI先给方案再执行

在执行前，先告诉我你打算怎么做（列个计划），我确认后你再开始。

技巧5：不满意就让它改

  • "太长了，精简到一半"
  • "语气太正式了，改轻松一点"
  • "第三部分不对，我的意思是……"
  • "重新做，这次重点突出XX"

🧩 附录B · 如何把指令做成Skill技能

什么是Skill？

Skill（技能）= 把一条你常用的指令存起来，下次点一下就能自动执行，不用重复打字。

适合做成Skill的场景：每周/每月都要做的工作、有固定格式的工作、固定的文件整理规则。

创建Skill的步骤

  1. 在workbuddy找到"创建技能/Skill"入口
  2. 给技能起个名字（如周报生成器、发票整理）
  3. 把你的指令填进去（把会变的部分留作每次输入）
  4. 测试一下，不满意就改指令
  5. 下次直接用：点技能→补充当天信息→执行
